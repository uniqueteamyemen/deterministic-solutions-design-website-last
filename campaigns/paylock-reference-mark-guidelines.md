# PayLock Reference Mark — Usage Guide v1.0

**Status:** Production identity asset for the managed DS&D website and explanatory material. This document governs visual use only; it does not claim trademark registration, payment capability, provider certification, or release readiness.

## Meaning

The mark is an abstract **P → reference → L** relationship. It does not depict a lock.

| Element | Meaning | Visual role |
| --- | --- | --- |
| `P` | Named event or protocol path | Graphite opening state |
| Horizontal river line | Shared reference or readable trace | Connection that can be inspected |
| Oxide point and vertical mark | Consequential proof point | One detail that changes the state meaning |
| `L` | Readable state | Graphite resulting state |

The mark supports the product statement: **named execution signals, readable proof path.** It must never be paired with language that says PayLock moves money, controls funds, guarantees delivery, or replaces a provider’s own policy.

## Use rules

Keep a clear area equal to at least the diameter of the oxide point on every side. Use the full-colour version on porcelain or very light mineral fields. The compact component may be used in product navigation only when the `P`, reference point, and `L` remain recognisable.

| Do | Do not |
| --- | --- |
| Use graphite for event/state, river blue for reference, and one oxide point for proof. | Add padlocks, keyholes, cards, coins, chains, checkout icons, or bank imagery. |
| Keep the line straight and the point singular. | Duplicate oxide points, add decorative data streams, glow, gradients, neon, or circuit motifs. |
| Pair it with bounded product language and a readable evidence route. | Present it as a guarantee of payment, access, delivery, or provider policy. |
| Use generous clear space and a calm editorial field. | Enclose it in a pill, app icon, or generic SaaS badge. |

## Copy pairings

**Preferred:** “Named execution signals. Readable proof path.”

**Preferred:** “A product direction for bounded delivery evidence.”

**Avoid:** “Secure payments.”

**Avoid:** “The lock that guarantees delivery.”

## Review test

Before use, ask:

> Does this mark make one named event, its shared reference, and its readable proof boundary clearer?

If the answer is no, remove the visual treatment rather than decorating the product.
