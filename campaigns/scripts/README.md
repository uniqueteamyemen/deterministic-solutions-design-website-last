# DS&D Short-Video Scripts

These scripts are **approval-ready generation briefs**, not publication approval. Each video is an original 15-second vertical concept. It may use a narrated or captioned campaign line, but it must not present an illustrative scene as a historical fact, use third-party trademarks, imitate a real person, or be published without separate owner confirmation.

The video generator should produce **no embedded typography**. Use the approved caption in the platform post or a separately approved caption track, because the campaign source text must remain accurate and readable.
